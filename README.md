## Projects

**promo-scraper-es** (Python, Playwright). Scrapes active contests, cashback offers and brand promotions in Spain into one spreadsheet row per promotion. It never invents a value: a field it cannot take from the page with a stated rule stays empty and is flagged. It checks `robots.txt` before every request and does not hide that it is a bot. Status: single-author prototype, run by hand once a week, no automated tests.

**fitwell-portfolio** (Next.js, TypeScript, Supabase). A personal fitness tracker in one place: activity, calories, macros and water on a daily dashboard, history, progress charts, goals and plans. Works on a phone as a PWA. Status: personal project in progress. The chat and photo sections are empty placeholders: no AI feature works yet.

**loyalty-platform** (React, TypeScript, Express, Prisma, PostgreSQL). A digital loyalty card for merchants, kept in the customer's wallet, with a merchant dashboard that also works offline. Status: personal project, last update June 2026.
